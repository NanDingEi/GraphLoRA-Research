# Late-layer residual ensemble experiments (Valid-only)

## Purpose

Run four post-processing comparisons on the existing D4 late-layer capture. This does not load the LLM, does not train CoRA, does not save a model checkpoint, and does not evaluate Test.

Input: the \`layer_logits_valid.npz\` and matching \`diagnostics.json\` generated by \`cora_late_layer_diag.py\`.

The script requires the official score-mode check to identify \`yes_raw_logit\`, and independently verifies that L32 AUC matches the official aggregate AUC within 0.005.

## Four experiments

1. **L1_L32_BASE** — raw L32 Yes logit baseline.
2. **L2_GLOBAL_R31_RESIDUAL** — fit L31 as a linear function of L32 on each training fold, obtain the L31 residual, then fit a fold-local standardized logistic calibrator on [L32, residual].
3. **L3_USER_GATE_R31** — add L31 residual through a sigmoid gate. The gate uses sample logits/residual plus unlabeled per-user mean/std statistics computed separately within each fold.
4. **L4_USER_GATE_MULTI** — residualize L29/L30/L31 against L32, then use a user-context softmax mixture and a separate sigmoid strength gate.

All residualization and gate/calibrator fitting use training-fold users only. A user's samples never cross between train and held-out folds. Per-user context for held-out users uses only their unlabeled logits, not labels.

## Evaluation protocol

- 5-fold \`StratifiedGroupKFold(shuffle=True, random_state=42)\`.
- Primary comparison: mean fold AUC and user-macro UAUC computed over all out-of-fold predictions.
- Also report pooled OOF AUC, Brier score, accuracy, fold metrics, and fold-local gate parameters.
- This is exploratory Valid-only cross-validation. Do not call it Test performance and do not use these results as final test metrics.
- No full model or CoRA checkpoint is saved. Small fold-local calibration/gating parameters are written to JSON for audit.

## Server command

Run from the CoRA project root. Download this script to the project root so that it resolves \`out/\` and \`logs/\` correctly.

\`\`\`bash
cd /home/bbx/user_lx/CoRA_official

REV=44a35a6c8afcfe147ccc113938b50079502a222f
BASE=https://raw.githubusercontent.com/NanDingEi/GraphLoRA-Research/$REV/experiments/no31_cora_original

curl -fL --retry 3 "$BASE/cora_residual_ensemble.py" -o cora_residual_ensemble.py
python -m py_compile cora_residual_ensemble.py

# Dependency check. Only install if the import check fails.
python - <<'PY'
import numpy, scipy, sklearn
from sklearn.model_selection import StratifiedGroupKFold
print("numpy", numpy.__version__)
print("scipy", scipy.__version__)
print("sklearn", sklearn.__version__)
print("[RESIDUAL-ENV-OK]")
PY

# Uses the newest out/LATE_LAYER_DIAG_D4_C6*/layer_logits_valid.npz automatically.

CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
